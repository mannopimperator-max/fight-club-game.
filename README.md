# Fight Club

Игра: https://mannopimperator-max.github.io/fight-club-game./

## Версия 9: задания и популярность

- Кнопка «Задания» и отдельный баланс 📣 популярности доступны сверху на всех экранах.
- Канал задания — https://t.me/icebloodkz. Кнопка открывает канал в Telegram или браузере. Открытие ссылки не подтверждает подписку и не выдаёт награду. Обещанная награда за подтверждённую подписку: 10 обычных монет и 3 популярности.
- Подтверждение подписки пока не подключено. Для него нужен сервер с проверкой Telegram `initData`, вызовом `getChatMember` от игрового бота @Fightclubthechampionsjourney_bot, который должен быть администратором канала, и однократной выдачей награды в базе данных. Токен нельзя помещать в HTML, JavaScript или GitHub-репозиторий.
- Популярность уже можно заработать в игре: первые 100 тренировочных ударов — 1; первая победа над боссом — 1; каждый седьмой день подряд с получением ежедневной награды — 2. Достижения разовые, серия повторяется. Ранее выполненные достижения тоже можно забрать один раз.
- Существующая ежедневная награда 250 обычных монет сохранена. Кнопки в профиле и заданиях используют одно состояние: две награды за один день получить нельзя. Пропуск дня сбрасывает серию, сохраняя накопленные средства.
- Магазин популярности продаёт значки профиля: «Свой» — 20, «Звезда клуба» — 35, «Легенда клуба» — 50. Покупки сохраняются; снятие и повторное надевание бесплатны. На боевые характеристики значки не влияют.
- Сохранение остаётся локальным (`fightclub_demo_v1`). Старые монеты, параметры бойца, экипировка и покупки сохраняются. Серия учитывает календарь устройства; серверная синхронизация, платные покупки и проверка подписки не активированы.

Проверка логики без дополнительных зависимостей:

```sh
node tools/check-club-progress.cjs
```

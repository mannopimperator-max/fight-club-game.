# Исправленные контуры, версия 7.1

Версия 8.0 добавляет `skinny`, `wiry`, `average`, `scrawny`, `chubby`, `stocky`, `grizzled`, `lanky`, `teen` (19-летний юниор) и `worn`: отдельный `*-front-v8.png` и `*-back-v8.png` для каждого. Это согласованные рисунки, разделённые из исходных пар в `tools/body-source/`. У каждого ракурса собственные точки посадки одежды и татуировок в `assets/body-catalog.js`. Прежние пять типов сохранены.

`wide-front-v71.png` и `heavyweight-front-v71.png` заменяют исходные изображения с обрезанным левым краем руки. Контур восстановлен по исходным персонажам с помощью редактирования изображения. Размер рабочего PNG — 192 × 420, фон прозрачный. Положение спрайта соответствует общей системе координат экипировки.

Файлы используются напрямую в `pixelSources`. Атлет, накачанный, сухой и изображения со спины продолжают использовать существующие PNG.

`tools/check-customization.cjs` проверяет прозрачные поля по бокам и отсутствие длинного прямого среза руки. До исправления прямой край занимал 127 строк у широкого и 75 у тяжеловеса; после исправления самый длинный вертикальный участок — 17 и 12 строк соответственно.
